## 🚀 Featured Projects

### 🎪 [EventPulse – Intelligent Crowd & Hospitality Orchestrator](https://github.com/Urmila1945/EventPulse-Intelligent-Crowd-Hospitality-Orchestrator)
A real-time mega-event orchestration platform integrating accommodation, transport, and crowd analytics. It predicts bottlenecks and optimizes visitor flow across the city using AI-driven capacity management.

**Tech:** TypeScript • AI/ML • Real-time Analytics

### 🤖 [AI-Powered Influencer Intelligence Platform (Ratefluencer AI)](https://github.com/Urmila1945/AI-powered-influencer-intelligence-platform)
Uses AI, machine learning, and social media analytics to identify high-potential influencers before they become mainstream, with authenticity and engagement analysis.

**Tech:** JavaScript • React • Node.js • AI/ML

### 📄 [PDF Assistant](https://github.com/Urmila1945/PDF_Assistant)
A PDF-powered AI chat app built with React, Node.js, and RAG architecture. Upload documents, ask questions, and get intelligent answers using the Gemini API.

**Tech:** React • Node.js • RAG • Gemini API

### ✍️ [Handwritten Digit Recognizer](https://github.com/Urmila1945/Handwritten-Digit-Recognizer)
A CNN model trained on MNIST with real-time digit prediction, confidence scoring, and multi-digit recognition.

**Tech:** CNN • MNIST • JavaScript • Deep Learning

### 📉 [Customer Churn Prediction](https://github.com/Urmila1945/Customer_churn_prediction)
Predicts whether a customer may leave a service using machine learning and historical data, with insights through an interactive dashboard.

### 💬 [Sentiment Analysis on Twitter Data](https://github.com/Urmila1945/Sentiment-Analysis-on-Twitter-Data-NLP-Based-Tweet-Classifier)
Developed during my internship at Codec Technologies. Classifies tweets as Positive 😊, Negative 😠, or Neutral 😐 using NLP techniques with NLTK.

### 🏠 [QuickServe – Localized Home Services Discovery & Booking](https://github.com/Urmila1945/QuickServe-Localized_Home_services_Discovery_Booking)
A service booking platform for easily scheduling and managing service appointments through a simple, user-friendly interface.

### 🥗 [SmartBite](https://github.com/Urmila1945/SmartBite)
An AI-based health tracker with grocery optimisation.
